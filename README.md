# 合一AI数字员工Skills构建元技能

出品：**合一AI效能实验室**  
Slogan：**教系统不教工具**  
版本：v2.2（学员独立包）  
定位：合一线学员交付物——把重复岗位能力固化成可测、可迭代的数字员工 Skill 工具包。

## 给谁用

- 想把「天天重复做的 AI 任务」固化成可复用 Skill 的学员与职场人
- 需要一套造 → 测 → 迭 → 治闭环，而不是只会写一版提示词的人
- 使用 Claude Code / Codex / Cursor / WorkBuddy / Obsidian 等任意支持 Skill 目录的工具

## 和「本体建模」的关系

- **本体建模**：钉业务真相（对象、规则、角色、流程），给人和 AI 一份可追溯的业务定义
- **本包**：固化数字员工岗位能力（可触发、可测、可迭代的 Skill）
- 二者互补：先把业务说清楚，再把重复执行能力做成岗位说明书

## 五件套关系（文字图）

```text
提示词生成  ──(任务重复且标准明确)──►  Skill生成
                                          │
                                          ▼
                                       Skill测试
                                      ╱         ╲
                              全通过               有失败
                                 │                   │
                                 ▼                   ▼
                           升版本 / 上线           Skill迭代
                                                     │
                                                     └──► 再测（闭环）
任意环节出现多 skill 重叠 / 过期 / 边界打架
                                          │
                                          ▼
                                       Skill治理
```

| 文件夹 | frontmatter name | 干什么 |
|---|---|---|
| 提示词生成 | `prompt-generator` | 写/改一次性高质量提示词；复杂且值得固化时交接 Skill生成 |
| Skill生成 | `skill-builder` | 五条件判断 → 分型 → 需求卡 → 九块结构 → 按风险装刹车 |
| Skill测试 | `skill-tester` | 触发/质量/冲突/上线验收，只出报告不修 |
| Skill迭代 | `skill-iterator` | 按失败点每次只改一处，留迭代记录，交回复测 |
| Skill治理 | `skill-governor` | 全库巡检、重叠冲突、合并废弃、经验回写建议 |

## 快速开始

1. 读本目录的 `安装说明.md`，把五个子文件夹拷进你当前工具的 skills 根目录
2. 按所用工具刷新/重启，确认能用 `/` 或等价方式唤起（如 `skill-builder`）
3. 从 `学员手册.md` 的推荐练习路径开始：先造一个原子 Skill，再走测→迭→治

## 使用约定（产品级）

- **落盘门禁**：先预览，用户明确说「保存 / 落盘 / 安装」后再写入
- **默认写入位置**：用户指定目录，或当前工作区的 `skills/<name>/`
- **双目录同步**：仅当你同时维护 Claude Code（`.claude/skills`）与 Codex（`.agents/skills`）时，才询问是否镜像；不默认假设任何个人知识库
- **索引**：可选维护本包或工作区的 skills 索引表；不假设仓库里已有「技能中心」

## 可选附件

- `SKILLS_INDEX.md`：技能清单空模板，复制到你的 skills 根目录维护；非运行必需。
